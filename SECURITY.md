# Security

Roletrail is intended for a single trusted user on localhost. It has no account system. Do not deploy its API publicly without adding authentication, authorization, transport security and deployment review.

Never include real candidate files, email credentials, Telegram API credentials/sessions, private application links, databases or logs in an issue or pull request. Redact screenshots and use synthetic records for reproduction. If a secret is published, revoke it at its provider; deleting a file from the latest commit does not remove it from history.

Report potential vulnerabilities privately through the repository's GitHub security reporting facilities when available. Otherwise, open a minimal issue asking for a private reporting channel without including exploit details or personal data.
