# Contributing

Use synthetic fixtures and keep personal state out of Git. Run the Python suite, frontend tests, production build and public-tree check before opening a pull request.

Changes to eligibility must preserve explicit geography, work-right, language, seniority and blacklist restrictions. Keep source dates separate from crawl/repost dates. Never turn missing evidence into affirmative eligibility or a fabricated publication date. Inferred visa support must remain distinct from an explicit sponsorship promise.

Submitted application materials and historical outcomes are protected records. Keep source integrations read-only unless a new outbound action has a separate explicit user flow.
